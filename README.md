# Česká slovíčka

Picture flash cards for A1 Czech nouns, Czech → English, one child-friendly
inline SVG per word, colour-coded by gender (F red, Ma dark blue, Mi light
blue, N green, the Czech Step by Step convention). Feminine and neuter decks
are done; masculine is next. No build step; open `index.html`.

- `index.html` – the page: cards grouped by topic, show/hide Czech or English,
  tap a card to reveal, 🔊 speaks the word with the browser's Czech voice.
- `words.js` – shared helpers and the pilot deck.
- `words/*.js` – one deck per topic (feminine) and `words/n-*.js` (neuter), each
  pushing entries onto `WORDS`.
- `a1-feminine.md`, `a1-neuter.md` – the word lists the decks are drawn from.
- `STYLE.md` – drawing rules and palette for new pictures.
- `words.json` – generated by `tools/export.py`: every card as one JSON object
  (cs, en, pattern, gender, topic, svg), for reuse outside the page.
- `tools/validate.py` – checks every SVG fragment; `tools/render.py <topic|all|word…>`
  renders a contact sheet PNG into `tools/out/` (needs the snap Chromium).
