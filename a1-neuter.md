# A1 Czech: neuter nouns

Draft word list for the picture-card deck, same format as `a1-feminine.md`.
Grouped by topic, not by frequency. Colour on the cards: green.

Patterns: **město** (hard, -o), **moře** (soft, -e), **kuře** (-e, gen. -ete),
**stavení** (-í). Latin words in -um (muzeum, datum) decline like město with the
-um dropped (muzea, data).

## Notes for the drawings

- The abstract ones (jídlo, pití, počasí, zdraví, cvičení, zaměstnání,
  povolání, oblečení, jméno, příjmení, datum, číslo, slovo, písmeno) need a
  strong single metaphor each; worth agreeing before drawing.
- dopoledne / poledne / odpoledne / ráno can share one visual language: the
  same house-and-sun scene with the sun at different heights, plus a clock.
- pondělí / úterý reuse the PO ÚT ST ČT PÁ SO NE calendar strip from the
  feminine deck.
